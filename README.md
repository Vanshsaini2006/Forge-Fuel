# FORGE FUEL — Fitness & Sports Nutrition Storefront

A responsive, original, front-end-only e-commerce website concept for an academic/digital marketing project. It is inspired by common sports-nutrition storefront patterns, not a copy of MuscleBlaze or any other brand.

## Preview locally

1. Download and unzip the project.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. For the most reliable local testing, run a simple static server from this folder:
   - Python: `python -m http.server 8000`
   - Then open `http://localhost:8000`

All main store interactions run in the browser. Google Fonts are loaded from Google Fonts; if offline, the page falls back to system fonts.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example, `forge-fuel-storefront`).
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to provide the live URL.

## Included functionality

- Responsive layout for desktop, tablet and mobile
- Product catalogue with 12 fictional products
- Category filters, keyword search and sorting by price/rating
- Product quick-view modal
- Add-to-cart, quantity controls, remove item and persistent cart (local storage)
- Wishlist / saved products (local storage)
- Free-shipping progress indicator and demo coupon (`FORGE10`)
- Simulated checkout with a validation-only demo form
- Goal-based catalogue shortcuts
- Newsletter confirmation interaction
- FAQ accordion, navigation and toast notifications
- Custom CSS illustrations for product packaging (no product photography required)

## Important limitations

- Forge Fuel is a fictional brand. Product names, prices, discounts, ratings, nutrition numbers, testimonials and offers are placeholders made for a student project.
- Checkout is simulated. There is no payment gateway, real order creation, stock management, email service, analytics integration or backend.
- Do not collect real customer details with this prototype. The form exists only to demonstrate UI flow and does not send data to a server.
- Before adapting this into a real store, replace all placeholder copy with verified product/label information, review applicable Indian food and advertising regulations, and integrate secure ecommerce infrastructure.

## Brand concept

**Positioning:** Straightforward sports nutrition and everyday fitness essentials for students, early-career professionals and gym-goers who value clarity over hype.

**Voice:** Direct, energetic, grounded, inclusive, habit-driven.

**Visual system:** Near-black, acid lime, off-white, and muted product-specific colours; condensed display typography; editorial catalogue layouts; custom pack illustrations.

**Campaign line:** “Built in the reps.”

**Suggested project pitch:** Forge Fuel is a hypothetical direct-to-consumer fitness nutrition store designed around clear product discovery, goal-based browsing and low-friction shopping. The site demonstrates the awareness → consideration → add-to-cart → demo-checkout journey and can be evaluated as a digital marketing prototype.
